## Что это

Android-клиент Vitosamin (3x-ui, VLESS/Reality), форк Hiddify App 5.3.0
(Flutter + sing-box). Релизы собирает только GitHub Actions по тегу `v*`.

## Сборка и выпуск

`flutter build apk --release` (env: `.env-android.sh`); релиз — тег `vX.Y.Z` после
поднятия `version` в `pubspec.yaml`, собирает Actions (`docs/RELEASING.md`).
GitHub: `.sandbox/.gh-oauth-token`, keystore `.secrets/vitosamin-release.jks`.

  спокойный автоселект (явный ручной выбор, пинг `0` не падение, лог переключений).

- 2.0.0: гео-списки и доменные правила удалены; маршрутизация по приложениям
  (`include`-режим): выбранные приложения идут через VPN, остальные напрямую.
  Заготовка популярных приложений (`PopularApps`) применяется при первом запуске к
  установленным; кнопка «Популярные» в списке приложений; удалённые гео-правила
  вычищаются из сохранённого списка.
- Обновления: проверка GitHub Releases при каждом запуске и из «О приложении»,
  скачивание APK из релиза.

## Следующий шаг

- Установить 2.0.0: в «Настройки → Маршрутизация» проверить, что включён режим
  приложений, и что в списке отмечены установленные популярные (YouTube, Telegram…).
  Остальные приложения должны идти напрямую. Если нужно «весь трафик через VPN» —
  выключить маршрутизацию по приложениям или выбрать режим «все, кроме выбранных».
- Если какой-то сервис не в списке — прислать его, добавить в пресет.
- Повторный системный запрос VPN: нужен скриншот диалога и данные, нет ли второго
  VPN-приложения/always-on VPN. Код просит разрешение один раз через
  `VpnService.prepare`; если системный диалог повторяется, согласие не сохраняет
  ROM, а не логика приложения.

## Грабли и решения

- `android-actions/setup-android@v3` падает на раннере — workflow берёт SDK раннера.
- `flutter test` целиком падает на 27 тестах без `libsqlite3.so` (drift).
- В geosite-ru нет голого суффикса `ru`, а прямой DNS 1.1.1.1 режется на части
  мобильных сетей РФ.
