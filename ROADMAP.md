### Что выяснила разведка (важное для оценок)

- Добавление профиля по sub-ссылке в форке **уже работает целиком** (скачивание,
  заголовки `subscription-userinfo`, валидация ядром, автоактивация) — нам
  остаётся «код → sub_url» и экран ввода.
- **RU→direct почти из коробки**: при `region=ru` включено правило
  `bypassRegion` → `geosite-ru.srs + geoip-ru.srs → direct` (и DNS direct, без
  утечек). Правка = выставить регион по умолчанию. Риск: `.srs` тянутся с
  GitHub, из РФ возможен блок — нужен свой mirror или inline `.ru`.
- **Приоритетов серверов в ядре нет**: ядро строит `selector` с
  `Default=balance` (round-robin) и балансер `lowest` (least-delay). «Первый
  живой по приоритету» делаем в приложении: после `Connected` через gRPC
  `SelectOutbound` выбираем первый живой тег в порядке подписки и переключаем
  при недоступности. Оценка M (1.5–2 д), без патча ядра.
- Сборка на Linux без macOS реальна: Flutter 3.38.5, JDK 17, SDK 36,
  NDK 28.2.13676358, AAR ядра из релиза, `make gen` + `translate` +
  `android-libs`, затем `flutter build apk --debug`.
